--------------------------------------------------------------------
WHAT WAS ADDED
--------------------------------------------------------------------
1) FIVE RINGTONES — Account & Backup -> Notifications & Sound now has
   a "Reminder ringtone" dropdown with 5 choices:
     - Soft Chime   (default — see below)
     - Classic Beep (the original two-beep alarm this app already had)
     - Gentle Bell
     - Marimba Pop
     - Xylophone Trill
   Picking one saves it immediately and plays a short preview right
   away, so you can audition each one by just clicking through the
   dropdown (same pattern as a phone's "choose ringtone" screen).
   There's also a "Preview sound" button below to replay the current
   choice any time.

2) DEFAULT RINGTONE FOR NEW INSTALLS — brand-new accounts default to
   "Soft Chime" specifically because it's the quietest and gentlest of
   the five (a soft two-note chime, lower volume than the others) — a
   first-time user's very first reminder shouldn't be startling.
   Existing accounts (anyone who already had the app before this
   update) default to "Classic Beep" instead — the exact sound they
   were already used to hearing — so this update doesn't change
   anyone's existing alarm sound out from under them without asking.
   Either way, anyone can change it any time in Notifications & Sound.

3) "RINGTONE PLAYS FOR" DURATION — a second dropdown lets you choose
   how long the ringtone plays when a reminder fires: 1 / 2 / 3 / 5 /
   8 / 12 seconds (default: 3 seconds). Every ringtone's short note
   pattern automatically repeats back-to-back to fill however long
   you pick — a longer duration doesn't distort or slow down the
   sound, it just plays the same short pattern more times.

4) BILL REMINDERS STAY ON BY DEFAULT — double-checked and confirmed:
   "Bill due reminders" (db.settings.notifBills) and the Bills alarm
   sound switch (db.settings.sound.bills) were already both ON by
   default for new installs before this change, and still are — this
   update doesn't touch that. What actually plays when a bill
   reminder fires is now the chosen ringtone above.

--------------------------------------------------------------------
HOW IT'S BUILT (why it's safe)
--------------------------------------------------------------------
All five ringtones are short sequences of plain oscillator notes
(frequency + duration + waveform + volume), generated on the fly with
the same Web Audio approach the app's existing alarm beep already
used — nothing is downloaded, no audio files were added, no external
link or CDN of any kind is involved. This matches the app's existing
"generated on the fly with Web Audio, so nothing is ever loaded from
an external file or link" approach for sound, just extended from one
fixed two-beep pattern to five selectable ones.

--------------------------------------------------------------------
WHERE THINGS LIVE, IF YOU WANT TO TWEAK THEM LATER
--------------------------------------------------------------------
- Ringtone definitions: search index.html for "const RINGTONES=" —
  each entry is a small list of {t, f, d, type, g} notes (start time,
  frequency in Hz, note length, waveform, volume) plus a loopLen/gap
  used to repeat it for the chosen duration.
- Default IDs: "soft-chime" in defaultDb() (new installs) and
  "classic-beep" in migrateDb() (existing installs) — search for
  reminderRingtone in either function.
- Duration options: the <select id="selReminderDuration"> in the
  Notifications & Sound card (search "Ringtone plays for").
