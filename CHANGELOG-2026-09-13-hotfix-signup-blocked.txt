THIS ONE'S ON ME — WHAT WENT WRONG
--------------------------------------------------------------------
Your screenshot showed it exactly right: the pre-login "welcome
slides" carousel (4 slides ending in "Private by design") — this
already existed in your app before I touched anything — stopped
working. Tapping "Get started" (or "Skip") did nothing, which meant
nobody could reach the sign-up screen at all. Confirmed from your
screenshot and the code together.

CAUSE: in the last update (v47, the one-time post-signup menu tour),
I named its "close and continue" function finishOnboarding() — not
realizing this file already had a completely different, pre-existing
finishOnboarding() function, used by that welcome-slides carousel to
hide itself and reveal the actual sign-in screen. JavaScript allows
two functions with the same name in the same file; whichever is
defined LAST silently overrides the other, with no error or warning
anywhere. Mine was defined later in the file, so it silently replaced
the original — meaning "Get started"/"Skip" on the welcome slides
were, from that point on, running my brand-new-menu-tour cleanup code
instead of the real "show the sign-in screen" code. That's the whole
bug: one accidental duplicate name, nothing more, and nothing to do
with your data or account setup.

I should have checked for a name collision against the rest of the
file before introducing a new function name, not just checked that my
own new code worked in isolation — noted for every update from here.
